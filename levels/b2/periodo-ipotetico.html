Il Periodo Ipotetico (I e II tipo)

Real and possible/unreal "if" sentences.

ObjectivesExplanationRulesExamplesCommon MistakesPracticeSummaryRelated

Introduction

Italian hypothetical sentences are built from a matched pair of tenses/moods in the se-clause and the main clause — get the pairing right, and the whole sentence falls into place.

By the end of this lesson you can…

  • Form the first type (real, likely) hypothetical sentence
  • Form the second type (possible but unlikely, or contrary-to-fact present) hypothetical sentence
  • Match the correct tense/mood in the se-clause and the main clause

Explanation

Explanation

The first type describes a real or likely condition: se + present indicative, main clause in the present or future. The second type describes something possible but unlikely, or contrary to fact right now: se + congiuntivo imperfetto, main clause in the present conditional. (The third type, for the impossible past, comes at C1.)

Grammar Rules

The Rules

a) First type — real/likely

Se + presente indicativo, presente/futuro: Se piove, resto a casa. / Se piove, resterò a casa. (If it rains, I'll stay home.)

b) Second type — possible/unreal

Se + congiuntivo imperfetto, condizionale presente: Se avessi più tempo, viaggerei di più. (If I had more time, I'd travel more — implying I don't, right now.)

c) Order can flip

The main clause can come first: Viaggerei di più se avessi più tempo. — same meaning, just reordered.

Examples

See It in Action

  • Se ho tempo stasera, ti chiamo.
    If I have time tonight, I'll call you.
  • Se studi di più, passerai l'esame.
    If you study more, you'll pass the exam.
  • Se fossi in te, non lo farei.
    If I were you, I wouldn't do it.
  • Se avessimo una macchina, andremmo al mare più spesso.
    If we had a car, we'd go to the seaside more often.
  • Comprerei quella casa se costasse meno.
    I'd buy that house if it cost less.

Common Mistakes

Watch Out For

AvoidSe avrei più tempo, viaggerei di più.

Use insteadSe avessi più tempo, viaggerei di più.

The se-clause of the second type needs the congiuntivo imperfetto (avessi), never the conditional — the conditional only goes in the main clause.

AvoidSe piovesse, resto a casa. (mixing types)

Use insteadSe piove, resto a casa. / Se piovesse, resterei a casa.

The se-clause tense/mood must match the main clause type — congiuntivo imperfetto pairs with the conditional, not the present indicative.

Summary

Review

  • First type (real/likely): se + presente indicativo, presente/futuro.
  • Second type (unreal/unlikely, present): se + congiuntivo imperfetto, condizionale presente.
  • The conditional never appears in the se-clause itself, only in the main clause.
